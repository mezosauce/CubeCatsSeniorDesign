## Project Background
The HABSat-1 mission is a CubeSat project that aims to monitor harmful algea blooms in the great lakes region.
The HABSat-1 satellite will be equipped with a hyperspectral imager to capture high-resolution images of the water surface, which will be processed and analyzed to detect and track the presence of harmful algae blooms.

## Project Description
In collaboration with the CubeCats organization, this project focuses on the design, implementation, and verification of the initial prototype flight software for the On-Board Computer (OBC) on the HABSat-1 mission.
The flight software shall establish core Command and Data Handling (CDH) capabilities across satellite subsystems and the ground station.
It will also be able to execute autonomous and scheduled tasks across mission flight states.
